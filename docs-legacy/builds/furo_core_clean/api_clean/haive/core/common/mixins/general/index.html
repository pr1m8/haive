haive.core.common.mixins.general¶

General-purpose mixins providing basic functionality for Haive components.

This package contains fundamental mixins that provide core functionality like ID management, serialization, state tracking, and versioning. These mixins are designed to be lightweight and composable, making them suitable for inclusion in a wide variety of components.

Available mixins: - IdMixin: Basic ID generation and management - MetadataMixin: Key-value metadata storage - SerializationMixin: Enhanced serialization capabilities - StateMixin: State tracking and validation - TimestampMixin: Creation and modification timestamp tracking - VersionMixin: Version tracking and compatibility checking

Usage:

```python from pydantic import BaseModel from haive.core.common.mixins.general import (

IdMixin, TimestampMixin, VersionMixin

)

class MyComponent(IdMixin, TimestampMixin, VersionMixin, BaseModel):

name: str

def __init__(self, **data):

super().__init__(**data) # Now the component has ID, timestamp, and version capabilities

```

class haive.core.common.mixins.general.StateMixin(*, state: str = 'active', state_history: list[dict[str, ~typing.Any]] = <factory>)[source]¶

Bases: BaseModel

Mixin for state tracking with validation and comprehensive history.

This mixin adds state management capabilities to Pydantic models, allowing objects to track their current state and maintain a complete history of state transitions with timestamps and optional reasons.

The mixin is designed to be composable with other BaseModel classes and provides thread-safe state transitions with automatic history tracking.

state¶

Current state of the object (defaults to “active”).

Type:

str

state_history¶

Chronological list of all state changes with metadata.

Type:

list[dict[str, Any]]

Example

>>> class Task(StateMixin, BaseModel):
...     name: str
>>> task = Task(name="Process data")
>>> task.change_state("running", "Starting execution")
>>> task.change_state("complete", "Finished successfully")
>>> task.is_in_state("complete")
True
>>> len(task.get_state_changes())
2

Change state and automatically track the transition in history.

This method updates the current state and records the transition in the state history with a timestamp and optional reason.

  • reason – Optional explanation for the state change.

Example
