haive.core.engine.document.loaders.sources.source_base¶

Base source classes for document loaders.

Sources are data models that represent where documents come from. They don’t load documents themselves - they just hold the configuration and metadata needed by loaders.

Classes¶

  • BaseSource - Abstract base class for all document sources.* LocalSource - Base class for local file sources.* DirectorySource - Source for directory of files.* RemoteSource - Base class for remote sources with credential support.* DatabaseSource - Base class for database sources.* CloudSource - Base class for cloud storage sources.
