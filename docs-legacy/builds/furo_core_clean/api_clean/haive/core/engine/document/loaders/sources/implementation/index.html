haive.core.engine.document.loaders.sources.implementation¶

Enhanced Source Implementation for Document Engine.

This module provides enhanced source type implementations adapted from the original project_notes with proper integration into the Haive document engine framework.

Classes¶

  • SourceType - Enhanced source type classification.* CredentialType - Types of credentials supported.* Credential - Credential information for authenticated sources.* CredentialManager - Manages credentials for various source types.* EnhancedSource - Enhanced base class for document sources.* LocalFileSource - Source for local files.* LocalDirectorySource - Source for local directories.* WebUrlSource - Source for web URLs.* DatabaseSource - Source for database connections.* CloudStorageSource - Source for cloud storage.* TextInputSource - Source for direct text input.* SourceRegistry - Registry for managing source types.
