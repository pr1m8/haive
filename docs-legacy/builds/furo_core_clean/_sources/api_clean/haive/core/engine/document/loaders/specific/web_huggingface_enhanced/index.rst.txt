
haive.core.engine.document.loaders.specific.web_huggingface_enhanced
====================================================================

.. py:module:: haive.core.engine.document.loaders.specific.web_huggingface_enhanced

   Enhanced HuggingFace Loaders with Additional Features.

   This module contains enhanced HuggingFace loaders for papers, collections,
   organizations, and extended dataset/model features.







Classes
-------

* :py:class:`HuggingFacePapersSource` - HuggingFace Papers loader for academic papers linked to models/datasets.* :py:class:`HuggingFaceCollectionsSource` - HuggingFace Collections loader for curated model/dataset collections.* :py:class:`HuggingFaceOrganizationsSource` - HuggingFace Organizations loader for organization profiles and resources.* :py:class:`HuggingFaceExtendedDatasetSource` - Extended HuggingFace Dataset loader with additional features.* :py:class:`HuggingFaceModelCardSource` - HuggingFace Model Card loader with extended information.* :py:class:`HuggingFacePapersLoader` - Custom loader for HuggingFace Papers.* :py:class:`HuggingFaceCollectionsLoader` - Custom loader for HuggingFace Collections.* :py:class:`HuggingFaceOrganizationsLoader` - Custom loader for HuggingFace Organizations.* :py:class:`ExtendedHuggingFaceDatasetLoader` - Extended wrapper for HuggingFace Dataset loader.* :py:class:`HuggingFaceModelCardLoader` - Custom loader for HuggingFace Model Cards with extended info.
