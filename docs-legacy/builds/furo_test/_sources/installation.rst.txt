Installation
============

Installing Haive
----------------

You can install Haive using pip:

.. code-block:: bash

   pip install haive

Or using Poetry:

.. code-block:: bash

   poetry add haive

Development Installation
------------------------

For development, clone the repository:

.. code-block:: bash

   git clone https://github.com/will-astley/haive.git
   cd haive
   poetry install

Requirements
------------

- Python 3.8+
- Poetry (for development)
- LangChain
- Pydantic v2
- AsyncIO support
