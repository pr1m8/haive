
haive.core.engine.document.loaders.sources.source_types
=======================================================

.. py:module:: haive.core.engine.document.loaders.sources.source_types

.. autoapi-nested-parse::

   Comprehensive source type system with proper typing for all langchain_community loaders.

   This module defines the complete hierarchy of source types to support all 231
   langchain_community document loaders with proper categorization and typing.

-------

* :py:class:`SourceCategory` - High-level source categories for organization.* :py:class:`CredentialType` - Types of credentials required by sources.* :py:class:`LoaderCapability` - Capabilities that loaders can have.* :py:class:`SourceCapabilities` - Capabilities and characteristics of a source type.* :py:class:`BaseSource` - Enhanced base class for all document sources with comprehensive typing.* :py:class:`LocalFileSource` - Base for local file-based sources.* :py:class:`RemoteSource` - Base for remote sources requiring authentication.* :py:class:`DatabaseSource` - Base for database sources.* :py:class:`CloudStorageSource` - Base for cloud storage sources.* :py:class:`DirectorySource` - Base for directory-based sources with bulk loading.* :py:class:`MessagingSource` - Base for messaging platform sources.* :py:class:`BusinessSource` - Base for business system sources (CRM, productivity tools).* :py:class:`AcademicSource` - Base for academic and research sources.* :py:class:`MediaSource` - Base for media platform sources (video, audio).* :py:class:`KnowledgeSource` - Base for knowledge management sources.* :py:class:`DevelopmentSource` - Base for development and version control sources.* :py:class:`PDFSource` - PDF document source with multiple processing options.* :py:class:`WebScrapingSource` - Web scraping source with browser automation.* :py:class:`DatabaseQuerySource` - Database source with custom query support.* :py:class:`BulkDirectorySource` - Directory source optimized for bulk loading.
