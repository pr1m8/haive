# Documentation Maintenance

**Purpose**: Documentation maintenance, cleanup, and optimization tools  
**Usage**: Maintaining documentation quality, fixing issues, and optimizing build processes

## 📄 Current Scripts

### Documentation Optimization

- **`update_docs_structure.py`** - Restructure documentation organization
- **`fix_rst_syntax.py`** - Repair RST formatting issues
- **`optimize_sphinx_config.py`** - Sphinx configuration optimization

### Content Management

- **`update_api_docs.py`** - API documentation maintenance
- **`clean_orphaned_files.py`** - Remove unused documentation files
- **`validate_cross_references.py`** - Fix broken internal links

## 🚀 Common Tasks

### Documentation Health

```bash
# Comprehensive documentation maintenance
poetry run python scripts/maintenance/docs/update_docs_structure.py

# Fix formatting issues
poetry run python scripts/maintenance/docs/fix_rst_syntax.py

# Optimize configuration
poetry run python scripts/maintenance/docs/optimize_sphinx_config.py
```

### Content Cleanup

```bash
# Remove orphaned files
poetry run python scripts/maintenance/docs/clean_orphaned_files.py

# Validate and fix links
poetry run python scripts/maintenance/docs/validate_cross_references.py
```
