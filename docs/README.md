# Haive Documentation

This directory contains all organized documentation for the Haive project.

## 📂 Structure

```
docs/
├── guides/                    # User and developer guides
│   ├── CLAUDE.md             # Main navigation hub
│   ├── CLAUDE_QUICKREF.md    # Essential quick reference
│   ├── QUICK_TEST.md         # Testing guide
│   ├── QUICK_DISCOVERY.md    # Discovery system guide
│   └── FRONTEND_INTEGRATION_GUIDE.md
├── agents/                    # Agent-specific documentation
│   ├── CLAUDE_AGENTS.md      # Agent documentation hub
│   ├── CLAUDE_AGENTS_CONVERSATIONAL.md
│   ├── CLAUDE_AGENTS_TASK.md
│   └── CLAUDE_AGENT_TEMPLATE.md

│   ├── DOCUMENTATION_STANDARDS.md
│   └── DOCUMENTATION_SYSTEM_OVERVIEW.md

│   └── CLAUDE_DISCOVERY_SYSTEM.md
└── source/                    # Sphinx documentation source
    ├── agents/               # Agent showcase

    └── guides/               # User guides (RST format)
```

## 🚀 Quick Start

1. **New to Haive?** Start with [guides/CLAUDE.md](./guides/CLAUDE.md)
2. **Need quick commands?** See [guides/CLAUDE_QUICKREF.md](./guides/CLAUDE_QUICKREF.md)
3. **Building agents?** Check [agents/CLAUDE_AGENTS.md](./agents/CLAUDE_AGENTS.md)
4. **Writing docs?** Follow [standards/DOCUMENTATION_STANDARDS.md](./standards/DOCUMENTATION_STANDARDS.md)

## 📝 Documentation Levels

1. **Professional Documentation** (`source/`) - Sphinx-generated user docs
2. **Developer Documentation** (`guides/`, `agents/`) - Developer guides
3. **Working Notes** (`/project_docs/`) - Informal development notes
