Beta Status and Roadmap
=======================

.. warning::

   **BETA STATU***S**: The Haive framework is currently in beta. APIs and functionality may change.**

Current Status

--------------

Haive is under active development and is currently in beta. This means:
***********************************************************************
* Core functionality is working and usable*
*******************************************
* APIs and interfaces may change between versions*
* Some features are still being refined and enhanced*
* Documentation is being actively expanded*
* We recommend pinning to specific versions in production environments*

Known Issues

------------
************
* Documentation autosummary may have gaps for some modules*
***********************************************************
* Some API references may be incomplete*
* Module organization is still evolving*

Roadmap

Here's what we're working on:
*****************************
* **Documentation Improvement***s**:**
  - Complete API reference documentation
  - More code examples and patterns
  - Better navigation and search
  - Expanded tutorials
**********************
* **Framework Enhancement***s**:**
  - Additional agent patterns
  - More robust state management
  - Enhanced error handling and debugging
  - Performance improvements
****************************

  - Better documentation for available tools
  - Simplified tool creation
****************************
* **Integratio***n**:**

  - Enhanced vector store support
  - Simplified deployment options
