Package Overview
----------------

**haive-core**

   Core infrastructure including engine, state management, and graph components.

**haive-agents**

   Pre-built agent implementations including SimpleAgent, ReactAgent, RAG agents, and multi-agent systems.

**haive-tools**

   Tool integrations for search, calculations, file operations, and external APIs.

**haive-games**

   Game environments and agents for chess, poker, debate, and other strategic games.

**haive-mcp**

   Model Context Protocol integration for connecting to external tools and services.

**haive-dataflow**

   Streaming and data processing components for real-time agent workflows.

**haive-prebuilt**

   Ready-to-use configurations and templates for common use cases.
