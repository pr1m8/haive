Agent API Reference
===================

This section provides comprehensive API documentation for all agent classes in the Haive framework.

Base Agent Classes
------------------

The base classes provide the foundation for all agent implementations:

- **Agent**: Abstract base class for all agents
- **GenericAgent**: Generic agent with type parameters for state/input/output
