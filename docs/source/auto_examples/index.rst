Haive Agent Examples
====================

Welcome to the Haive Agent Framework example gallery!

These examples demonstrate how to create, configure, and use various types
of AI agents in the Haive framework. Each example is self-contained and
shows different patterns and capabilities.

Getting Started
---------------

The examples are organized to show both the haive.agents and haive.core.engine
patterns for creating AI agents:

- **SimpleAgent Examples**: Easy-to-use agents from haive.agents
- **Core Engine Examples**: Advanced configuration-based agents from haive.core.engine  

Each example includes:

- Complete, runnable code
- Visual workflow diagrams
- Performance measurements
- Clear explanations

All examples use real LLM calls (no mocks) to demonstrate actual agent behavior.

Requirements
------------

Make sure you have configured your LLM provider:

- Set appropriate API keys in your environment
- Configure the AugLLMConfig for your chosen provider
- Ensure all dependencies are installed via poetry

Happy coding with Haive agents! 🤖
