## Example Structure

Each example includes:

- **Complete Code** - Full, runnable code you can copy
- **Explanation** - Clear explanations of key concepts
- **Common Patterns** - Best practices and idioms
- **Troubleshooting** - Solutions to common issues

## Running Examples

All examples can be run with:

```bash
# Clone the repository
git clone https://github.com/paulhyunkim/haive.git
cd haive/examples

# Install dependencies
poetry install

# Run an example
python quick_start/basic_agent.py
```
