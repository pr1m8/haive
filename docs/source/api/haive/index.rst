Navigation
----------

The API documentation is organized hierarchically:

- **haive** (root)
  
  - **core** → engine → base, aug_llm, document...
  - **agents** → simple → structured, v2...
  - **tools** → search, math, api...
  
Each level provides both an overview and direct access to submodules.
