Getting Started
---------------

.. note::
   All games are browser-based and require no downloads or installations. Simply click "Play Now" to begin your learning adventure!

.. tip::
   Create an account to save your progress, unlock achievements, and compete with friends on global leaderboards.

.. warning::
   Some games may require specific browser features like WebGL for optimal performance. We recommend using a modern browser like Chrome, Firefox, or Safari.
