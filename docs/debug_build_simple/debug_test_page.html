Build Information¶

To verify this page builds correctly with all extensions, check:

  1. Math renders properly

  2. Code blocks have syntax highlighting

  3. Copy buttons appear on code blocks

  4. Mermaid diagram displays

  5. Cards and grids layout correctly

  6. Cross-references resolve

  7. Todo items appear (if enabled)

  8. Graphviz diagram renders
