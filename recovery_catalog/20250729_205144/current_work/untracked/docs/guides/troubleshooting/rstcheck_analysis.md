## Detailed Analysis

### 1. Unknown Directive Issues

The main problem is that rstcheck is running in standalone mode and doesn't recognize Sphinx-specific directives:

- **`grid` directive** - From `sphinx_design` extension
- **`exec_code` directive** - From `sphinx_exec_directive` extension
- **`autoclass/automodule`** - From Sphinx autodoc
- **Custom directives** - Agent-specific documentation directives

**Root Cause**: rstcheck needs to be configured to recognize Sphinx extensions.

### 2. Python Code Block Errors

Multiple files have invalid Python syntax in code blocks:

#### Files with `await` outside function:
- `docs/source/guides/rag_agents.rst` (5 occurrences)

## Fix Strategy

### Phase 1: Configure rstcheck for Sphinx

Create `.rstcheck.cfg` or add to `pyproject.toml`:

```toml
[tool.rstcheck]
ignore_directives = [
    "automodule",
    "autoclass",
    "autofunction",
    "autoexception",
    "autodata",
    "automethod",
    "autoattribute",
    "autosummary",
    "grid",
    "grid-item",
    "grid-item-card",
    "exec_code",
    "agent-doc",
    "automodsumm",
    "toctree",
    "code-block",
    "literalinclude",
    "include",
    "image",
    "figure",
]
ignore_roles = [
    "class",
    "func",
    "meth",
    "attr",
    "exc",
    "obj",
    "mod",
    "data",
    "ref",
    "doc",
]
ignore_substitutions = [
    "version",
    "release",
    "today",
]
report_level = "warning"
ignore_languages = ["python"]  # Since we have async examples
```

### Phase 2: Fix Python Code Blocks

#### For `await` outside function:
Convert standalone await examples to proper async function examples:

```rst
# Before:
.. code-block:: python

   result = await agent.arun("Hello")

# After:
.. code-block:: python

   async def example():
       result = await agent.arun("Hello")
```

#### For indentation errors:
Ensure proper indentation in code blocks:

```rst
# Before:
.. code-block:: python

   def my_function():
   # Missing indentation

# After:
.. code-block:: python

   def my_function():
       # Proper indentation
       pass
```

### Phase 3: Fix RST Formatting

#### Title underlines:
```rst
# Before:
My Title
=====

# After:
My Title
========
```

#### Add missing blank lines:
```rst
# Before:
.. note:: Something
Next paragraph

# After:
.. note:: Something

Next paragraph
```

### Phase 4: Handle Template Files

