## 🔍 Why AutoAPI is Struggling

### The Namespace Package Challenge

AutoAPI is generating paths like:

```
api/src/haive/agents/...  ❌ Wrong
```

Instead of:

```
api/haive/agents/...      ✅ Correct
```

This happens because:

1. Your packages use `src/` layout
2. AutoAPI includes the `src` in module paths for namespace packages
3. The current path-fixing attempts aren't working properly

## 🎯 The Solution: Fix AutoAPI Configuration

### Option 1: AutoAPI Template Customization (Recommended)

Create custom templates to fix the module paths:

```python
# In conf.py

# 1. Set template directory
autoapi_template_dir = "_templates/autoapi"

# 2. Create custom templates that strip 'src.' prefix
# _templates/autoapi/python/module.rst
```

**Template Example** (`_templates/autoapi/python/module.rst`):

```jinja2
{{ obj.name|replace("src.", "") }}
{{ "=" * (obj.name|replace("src.", "")|length) }}

.. automodule:: {{ obj.name|replace("src.haive", "haive") }}
   :members:
   :undoc-members:
   :show-inheritance:
```

### Option 2: AutoAPI Event Handlers (Current Approach - Needs Fixing)

The current conf.py has event handlers, but they need enhancement:

```python
def autoapi_skip_member(app, what, name, obj, skip, options):
    """Skip members and fix module names."""
    # Fix the module name before processing
    if hasattr(obj, 'name'):
        if obj.name.startswith('src.'):
            # This is the issue - obj attributes are read-only
            # Need a different approach
            pass

    # Skip patterns
    skip_patterns = ['test_', '_test', 'debug', 'demo']
    if any(pattern in name.lower() for pattern in skip_patterns):
        return True

    return skip

# Better approach - post-process the generated files
def fix_autoapi_generated_files(app, exception):
    """Fix generated RST files after AutoAPI runs."""
    if exception:
        return

    import os
    import re
    from pathlib import Path

    api_dir = Path(app.srcdir) / "api"

    # Fix all generated RST files
    for rst_file in api_dir.rglob("*.rst"):
        content = rst_file.read_text()

        # Fix module paths
        content = re.sub(r'src\.haive', 'haive', content)
        content = re.sub(r'automodule:: src\.', 'automodule:: ', content)

        rst_file.write_text(content)
```

### Option 3: Sys.path Configuration (Cleanest)

Instead of adding `src` directories to sys.path, add the package directories:

```python
# Current (problematic)
for package in package_names:
    src_path = packages_dir / package / "src"
    sys.path.insert(0, str(src_path))

# Better approach
for package in package_names:
    # Add parent of src so imports work without 'src.'
    package_path = packages_dir / package
    sys.path.insert(0, str(package_path))

    # Also set up namespace package
    src_path = package_path / "src" / "haive"
    if src_path.exists():
        # This helps Python recognize it as a namespace
        import haive
        haive.__path__.append(str(src_path))
```

### 2. Update conf.py

```python
# ==============================================================================
# AutoAPI Configuration - Fixed for Namespace Packages
# ==============================================================================

# Path setup - add package roots, not src directories
for package in package_names:
    package_path = packages_dir / package
    if package_path.exists():
        sys.path.insert(0, str(package_path))

# AutoAPI configuration
autoapi_type = "python"
autoapi_dirs = [
    str(packages_dir / package / "src")
    for package in package_names
    if (packages_dir / package / "src").exists()
]
autoapi_root = "api"
autoapi_keep_files = True
autoapi_add_toctree_entry = True

# Critical for namespace packages
autoapi_python_use_implicit_namespaces = True

# Options
autoapi_options = [
    "members",
    "undoc-members",
    "show-inheritance",
    "show-module-summary",
    "imported-members",  # Show imported members too
]

# Ignore patterns - aggressive filtering
autoapi_ignore = [
    "**/test*/**",
    "**/*_test.py",
    "**/test_*.py",
    "**/tests/**",
    "**/testing/**",
    "**/fixtures/**",
    "**/conftest.py",
    "**/__pycache__/**",
    "**/migrations/**",
    "**/.git/**",
    "**/node_modules/**",
    "**/build/**",
    "**/dist/**",
    "**/*.egg-info/**",
    "**/examples/**",
    "**/example_*.py",
    "**/demo_*.py",
    "**/debug_*.py",
    "**/_*.py",  # Private modules
    "**/deprecated/**",
    "**/legacy/**",
    "**/experimental/**",
    "**/ui.py",
    "**/cli.py",
    "**/main.py",
    "**/app.py",
]

# Module naming fix
def fix_module_name(name):
    """Remove src. prefix from module names."""
    if name.startswith("src."):
        return name[4:]
    return name

# Connect to Jinja environment
def prepare_jinja_env(jinja_env):
    """Add our custom filters."""
    jinja_env.filters["fix_module_name"] = fix_module_name
    return jinja_env

autoapi_prepare_jinja_env = prepare_jinja_env
```

### 3. Create Custom Template

Create `docs/source/_templates/autoapi/python/module.rst`:

```jinja2
{% if not obj.display %}
:orphan:
{% endif %}

{{ obj.name|fix_module_name }}
{{ "=" * (obj.name|fix_module_name|length) }}

.. py:module:: {{ obj.name|fix_module_name }}

{% if obj.docstring %}
{{ obj.docstring|indent(3) }}
{% endif %}

{% block content %}
{% if obj.all %}
.. rubric:: Module Attributes

.. autosummary::
   :toctree:
   :template: custom-module-template.rst
{% for item in obj.all %}
   {{ item }}
{%- endfor %}
{% endif %}

{% for obj_item in obj.children %}
{{ obj_item.rendered|indent(0) }}
{% endfor %}
{% endblock %}
```
