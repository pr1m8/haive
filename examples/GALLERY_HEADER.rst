Haive Examples Gallery
======================

This gallery contains comprehensive examples demonstrating various features and capabilities
of the Haive AI Agent Framework.

.. contents:: Examples Overview
   :local:
   :depth: 2

Getting Started
---------------

These examples will help you understand how to use different components of Haive:

- **Agents**: Creating and configuring various types of agents
- **Tools**: Integrating tools and external services
- **Workflows**: Building complex multi-agent workflows
- **Games**: Using agents in game environments
- **Data Processing**: Stream processing with agents

Each example is self-contained and can be run independently.
